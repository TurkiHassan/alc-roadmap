02 المشكلة

تقرأ عن PCA فيجد «أوجد المتجهات الذاتية لمصفوفة التغاير»، وعن استقرار النماذج فيجد «تأكد أن جميع القيم الذاتية أصغر من 1 بوحدتها». لا شيء منها منطقي حتى تفهم ماذا تفعل المصفوفات بالفضاء هندسياً.

الفكرة المحورية

أعمدة المصفوفة هي أماكن هبوط متجهي الأساس [1,0] و[0,1] بعد التحويل — اعرف مصيرهما وعرفت التحويل كله.

03 مكتبة التحويلات

الدوران R(θ)

[[cosθ,−sinθ],[sinθ,cosθ]]

يدير النقاط على أقواس دائرية محافظاً على المسافات والزوايا. محدده دائماً 1

التكبير S

[[sx,0],[0,sy]]

يمدّ أو يضغط كل محور باستقلال. محدده = حاصل ضرب المعاملين

القصّ Shear

[[1,k],[0,1]]

يميل محوراً بإزاحة تناسب الآخر — المستطيلات تصبح متوازي أضلاع. محدده 1

التركيب: تطبيق تحويل A ثم B = ضرب المصفوفتين B @ A. والترتيب مهم: دوّر 90° ثم كبّر بـ(2, 0.5) يعطي نتيجة مختلفة عن التكبير ثم الدوران — ضرب المصفوفات غير تبديلي.

الانعكاس: مرآة عبر محور، مثل [[-1,0],[0,1]] عبر محور y. محدده −1: نفس المساحة لكن الاتجاه ينقلب.

04 القيم والمتجهات الذاتية

معظم المتجهات تغيّر اتجاهها عند التحول. المتجه الذاتي استثناء نادر: المصفوفة تكبّره فقط ولا تديره: A·v = λ·v. مثال: للمصفوفة [[2,1],[1,2]] المتجه [1,1] ذاتي بقيمة 3 (تمدد ثلاث مرات)، و[1,−1] ذاتي بقيمة 1 (يبقى كما هو).

التفكيك الذاتي: إذا كان للمصفوفة n متجه ذاتي مستقل فهي تتفتت إلى A = V·D·V⁻¹ — «ادخل إحداثيات المتجهات الذاتية، كبّر كل محور، وارجع». وهذه بصمة التحويل الحقيقية.

لماذا تهتم في AI؟

PCA: متجهات مصفوفة التغاير الذاتية هي المكوّنات الرئيسية وقيمها تقيس التباين الملتقط. الاستقرار: في الشبكات العودية قيمة ذاتية وحدتها > 1 تعني انفجار المخرجات، و< 1 تعني تلاشيها — مشكلة vanishing/exploding gradients في جملة واحدة. Spectral clustering وGNN: بنية البيانات مخبوءة في القيم الذاتية.

05 ابنِها بنفسك

  • 1 · مصانع التحويلات كل تحويل دالة تُرجع مصفوفته:
    python
    import math

def rotation_2d(t):
    c, s = math.cos(t), math.sin(t)
    return [[c, -s], [s, c]]

def scaling_2d(sx, sy):
    return [[sx, 0], [0, sy]]

def shearing_2d(kx, ky=0):
    return [[1, kx], [ky, 1]]

R = rotation_2d(math.pi / 4)
print(R)   # [[0.71,-0.71],[0.71,0.71]]
  • 2 · التركيب يثبت عدم التبادل
    python
    def mat_mul(a, b):
    return [[sum(a[i][k]*b[k][j] for k in range(len(a)))
             for j in range(len(b[0]))] for i in range(len(a))]

R = rotation_2d(math.pi/2); S = scaling_2d(2, 0.5)
print(mat_mul(S, R))   # [[0,-2],[0.5,0]]
print(mat_mul(R, S))   # [[0,-0.5],[2,0]]  <- مختلفة!
  • 3 · القيم الذاتية لـ 2×2 يدوياً المعادلة المميزة: λ² − (a+d)λ + det = 0
    python
    def eigenvalues_2x2(m):
    trace, det = m[0][0]+m[1][1], m[0][0]*m[1][1]-m[0][1]*m[1][0]
    disc = trace**2 - 4*det
    if disc >= 0:
        r = disc**0.5
        return ((trace+r)/2, (trace-r)/2)
    # قيم مركبة = دوران!
    from cmath import sqrt
    return ((trace+sqrt(disc))/2, (trace-sqrt(disc))/2)

A = [[2, 1], [1, 2]]
print(eigenvalues_2x2(A))   # (3.0, 1.0)
  • 4 · NumPy يختصر الطريق
    python
    import numpy as np
A = np.array([[2., 1.], [1., 2.]])
vals, vecs = np.linalg.eig(A)
# A @ v == λ * v لكل عمود v
D = np.diag(vals)
B = np.array([[3., 1.], [0., 2.]])
v, _ = np.linalg.eig(B)
print(np.allclose(v @ D @ np.linalg.inv(_), B))  # True

    • 06 الاختبار

    هل ثبت الدرس؟

    أجب عن الأسئلة. التغذية الراجعة فورية — والشرح يظهر بعد اختيارك، أو اضغط زر «أظهر الشرح» لرؤيته مباشرة دون إجابة.

    0/5 نتيجتك

    سؤال 1

    ماذا يعني أن v متجه ذاتي للمصفوفة A بقيمة λ=3؟

    ✓ A·v = 3v: الاتجاه ينجو من التحويل ويُضخَّم فقط. المتجهات الذاتية هي بصمة التحويل.

    سؤال 2

    لماذا يجب فحص وحدة القيم الذاتية في الشبكات العودية؟

    ✓ مضاعفة λ عبر خطوات زمنية متكررة: |λ|>1 انفجار، |λ|<1 تلاشٍ — جوهر مشكلة vanishing/exploding gradients.

    سؤال 3

    «دوّر ثم كبّر» مقابل «كبّر ثم دوّر» — النتيجة:

    ✓ S@R ≠ R@S عموماً: التركيب بترتيبات مختلفة ي reshapes الفضاء بشكل مختلف.

    سؤال 4

    قيم ذاتية مركبة (معقدة) تدل عادةً على:

    ✓ الأعداد المركبة تظهر حين لا يوجد اتجاه ثابت — التحويل يلفّ الفضاء بدل تمدده على محور.

    سؤال 5

    في PCA، ما دور متجهات مصفوفة التغاير الذاتية؟

    ✓ رتّب حسب القيمة الذاتية واحتفظ بأعلى k اتجاه — تقليص أبعاد مبني مباشرة على التفكيك الذاتي.

    07 المسرد

    المصطلحات التي ستراها في كل مكان

    Rotation Matrix
    مصفوفة تعيد النقاط على أقواس دائرية محافظة على المسافات؛ محددها 1 دائماً
    Rz(θ) حول محور z في 3D
    Shearing
    إزاحة تناسبية تحول المستطيل لمتوازي أضلاع؛ محددها 1
    [[1,k],[0,1]]
    Eigenvector
    اتجاه لا تدوره المصفوفة بل تضخّمه فقط — بصمة التحويل
    np.linalg.eig
    Eigenvalue
    معامل التضخيم؛ سالب = قلب اتجاه، مركب = دوران
    |λ|>1 → انفجار في RNN
    Eigendecomposition
    تفكيك A = V·D·V⁻¹ إلى اتجاهاته الأساسية ومقاديرها
    أساس spectral clustering
    Characteristic Equation
    المعادلة det(A−λI)=0 التي جذورها القيم الذاتية
    λ²−(a+d)λ+det=0 لـ 2×2
    Composition
    سلسلة تحويلات بضرب المصفوفات؛ B@A تعني طبّق A أولاً
    S @ R @ point
